# Sunday Gravy Studio website

Static HTML site for sundaygravystudio.com, hosted on GitHub Pages. No build step: edit the files, commit, push to `main`, and it deploys.

- `index.html` is the whole site (Home, Work, About, Contact as in-page views).
- `photos/` holds the 21 photos: `sg-XX.jpg` (1800px) and `sg-XX-t.jpg` (900px thumbnails).
- Logo: D4.3 "Meatball Lift" marker doodle, inline SVG in `index.html` and `favicon.svg`.
